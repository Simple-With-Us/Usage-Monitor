# Collector Coverage Audit

This helper is an unexecuted review candidate for UM-1649/UM-1654.  The default command prints an offline plan and performs no inspection, subprocess, credential read or write.  Live local inspection requires a separate parent release of reviewed bytes and `--audit-local-mac` on the existing authorized Mac SSH target as Jay; it refuses other OS/home contexts.  The helper does not create an SSH connection or modify trust.

The narrow scope is Kimi Code, ZCode, Muse Code, Muse, Antigravity, Grok and FX.  The existing UM-1652 parent owns collector installation/injection; the UM-1654 controller worker owns canonical key/map and mounted activation controllers.  This audit changes none of those surfaces.

Allowed observations are installed `VERSION` revision, SHA256 of six fixed installed script files, presence of current/previous symlinks without following their targets, seven fixed LaunchAgent plists and fixed-label `launchctl print` calls, and stat-only native source availability/freshness at the collector defaults.  Source walks stop after 20,000 entries and mark incomplete; no filenames or source paths are printed.  Installed files and plists are bounded to 1 MiB, must be regular and owned, and their path components cannot be symlinks.

Native Kimi wire files, ZCode databases, Muse session files, Grok transcripts, FX records, checkpoints and logs are never opened.  No SQLite connection is made, avoiding journal/shared-memory side effects.  No credentials, credential files, Infisical, Keychain, network API, receiver database, or Sentry store are accessed.  Plists and launchctl can contain private arguments/environment: raw data remains inside the process and only fixed boolean/integer fields are emitted; arbitrary arguments, environment values, command output and error messages are never relayed.  The helper does not read a token from those fields or use one.

Output uses only fixed producer labels, installed source hashes/revision, booleans, counts, byte sizes and age seconds.  No wall-clock time or application payload is emitted.  Files are opened read-only, no application state is written, and no job is loaded/unloaded or collector invoked.  Normal OS access-time changes are outside the application-write claim.  The native directories must remain trusted during inspection; results are not an atomic cross-process snapshot.

Run the offline plan with `python3 scripts/telemetry-hub/audit-collector-coverage.py`.  Offline tests use synthetic temporary fixtures only: `PYTHONDONTWRITEBYTECODE=1 python3 scripts/telemetry-hub/test_audit_collector_coverage.py -v`.  Streaming reviewed source over the existing SSH profile is a separate guarded operation; a guard refusal requires the approved routing decision, never a wrapper bypass.

Installed/loaded status and source presence establish only sender prerequisites.  Overrides in job configuration are not inspected, and a native file can exist without any usable usage records.  Direct Usage Monitor ACKs and independently stored ledger aggregates need their own authorized bounded read.  Hub acceptance/journal receipts and native Sentry stored receipts need separate reads.  This helper explicitly reports those boundaries as unverified and cannot declare delivery, billing coverage, deduplication or activation complete.
